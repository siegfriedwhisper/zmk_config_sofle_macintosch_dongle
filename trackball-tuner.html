🎯 轨迹球调参器

左半区 · bbtrackball · 通过 USB 串口实时调参，无需刷固件
未连接
⚠️ 用法：用 USB 线连接左手轨迹球半区到电脑 → 点「连接串口」选择设备（通常显示为 CDC ACM 或 USB Serial）→ 拖动滑条实时生效 → 点「保存到键盘」固化。需 Chrome / Edge 浏览器。
参数说明
· 灵敏度：整体加速强度缩放（100% = 出厂手感）
· 滚轮单次档数：每次滚轮发几档（1 = 精细，越大滚越快）
· 方向键阈值：多大位移才触发方向键
· 方向键重复间隔：方向键触发的最小间隔（ms）
· 移动判定窗：多久内算"正在移动"（ms），影响 LED 点亮时长
· 查表兜底：滚得慢时的基础像素（delta≥45ms 用此值）

所有改动即时生效；「保存到键盘」才写入 flash，断电重启后仍保留。
